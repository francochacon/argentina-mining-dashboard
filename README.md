# Argentina Mining Dashboard (Power BI)

## Objetivo
Dashboard para analizar exportaciones mineras de Argentina, con foco en:
- Año máximo exportado
- Variación interanual (YoY)
- Sector dominante
- Mineral dominante y participación
- Tendencia histórica (últimos años)

## Dashboard online
- Sitio del portfolio: https://francochacon.github.io/proyecto2/

## KPIs
- **Año más exportado:** año con mayor FOB total.
- **Variación interanual:** (FOB año - FOB año anterior) / FOB año anterior.
- **Mineral dominante:** GRUPO con mayor FOB en el año máximo.
- **% participación mineral dominante:** FOB mineral dominante / FOB total del año máximo.
- **% participación por sector:** FOB sector / FOB total del año máximo.
